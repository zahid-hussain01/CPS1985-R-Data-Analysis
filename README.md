# CPS1985 R Data Analysis

## Project Overview

This project analyzes the CPS1985 dataset using R and RStudio. It focuses on data handling, descriptive statistics, data filtering, variable selection, and data visualization.

## Objectives

- Understand and inspect the CPS1985 dataset
- Work with variables and observations in R
- Calculate descriptive statistics
- Filter and select data using `dplyr`
- Produce statistical summaries using `stargazer`
- Create bar charts using `ggplot2`
- Practice data visualization using ColorBrewer and Viridis

## Dataset

The project uses the CPS1985 dataset available through the `AER` package in R.

The dataset contains information related to workers, including variables such as:

- Wage
- Age
- Education
- Experience
- Gender
- Ethnicity
- Occupation

## Tools and Packages

The project was completed using:

- R
- RStudio
- AER

### Data Handling
